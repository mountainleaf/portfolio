## The stack, briefly

- **Nuxt 4** for the framework and file-based routing.
- **Nuxt UI v4** for accessible Vue components with Tailwind v4 theming.
- **Nuxt Content v3** for typed Markdown + YAML content collections.
- **Cloudflare Pages** for hosting, with a GitHub Actions workflow pushing on every commit to `dev`.
